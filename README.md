# آذان واچ — اپ گریڈ شدہ پیکیج

## فائلیں
- `index.html` — اردو ڈیش بورڈ
- `assets/css/app.css` — الگ اسٹائل شیٹ
- `assets/js/app.js` — گھڑی، تاریخ، نماز کے اوقات اور محفوظ ترتیبات
- `manifest.webmanifest` — انسٹال ہونے والی ویب ایپ کی بنیادی معلومات
- `service-worker.js` — HTTP/HTTPS ہوسٹنگ پر بنیادی آف لائن کیش

## چلانے کا طریقہ
`index.html` کو براؤزر میں کھولیں۔ مکمل PWA/Service Worker سہولت کے لیے اسے HTTPS ویب ہوسٹنگ یا localhost پر چلائیں۔ Tailwind اور فونٹ کے لیے انٹرنیٹ درکار ہو سکتا ہے۔

## اہم وضاحت
- نماز کے اوقات پہلے سے درج نمونے ہیں؛ اپنے علاقے کی مسجد کے مستند اوقات درج کریں۔
- موسم اب فرضی درجۂ حرارت نہیں دکھاتا؛ حقیقی موسم کے لیے API اور انٹرنیٹ درکار ہوں گے۔
- نوٹیفکیشن اور اسکرین روشن رکھنے کی سہولت براؤزر/ڈیوائس کی اجازت اور حدود کے تابع ہے؛ یہ بند براؤزر میں یقینی الارم کی ضمانت نہیں۔
- ڈیٹا اسی براؤزر کے localStorage میں محفوظ ہوتا ہے۔
